# Правила креативу (для content-creative)

Креатив будується ПЕРШИМ (до тексту): за Module 4 креатив стопить скрол, текст його підтримує.
Джерело контенту креативу — затверджена картка Idea Pool (hook draft + competence proof + format +
pillar + notes). Бренд — бренд-кіт клієнта (для Viktor — його персональний бренд; НІКОЛИ не мішати з клієнтськими).

## Формат-роутинг

| Format у картці | Що робимо | Реюз |
|---|---|---|
| **carousel** | 7-блочна структура (methodology §3.6) | скіл `linkedin-creative` з бренд-файлом клієнта; інакше верстка 1080×1350 за цими правилами |
| **infographic** | дата-віз або структурна (правила нижче) | скіл `linkedin-creative` з бренд-файлом клієнта; інакше форма за правилами нижче |
| **single image** | або власне фото автора (personal/TOFU), або брендований stat/quote-візуал | `linkedin-creative` (infographic, простий макет) / фото |
| **lead magnet** | обкладинка з комент-гейтом + робочий темплейт → PDF (не чеклист на сторінку) | скіл `linkedin-creative` з бренд-файлом клієнта; інакше окремий білд (Notion→PDF) |

**Бренд-файл.** `linkedin-creative` бере бренд з окремого JSON (кольори, шрифти, стиль заголовка,
чип, футер). Кіт клієнта лежить у теці клієнта (`./brand/<company>.json`), не всередині скіла; нема —
збери за `references/brand-kit.md` того скіла. Скіли `linkedin-carousel` / `infographic` прибиті до
бренду Victor Shulga і Figma: лише запасний шлях для його власних креативів, не для клієнтів.
| **text-only** | креатив НЕ потрібен → пропустити, одразу content-write | — |
| **video** | поза автоматизацією — позначити ручний крок | — |

## Карусель — 7 блоків (з methodology §3.6, ЖОРСТКО)
Обкладинка (хук) → Контекст → М'ясо (1 думка = 1 слайд) → Результати (докази) → Бонус → CTA.
Текст-підпис до каруселі = однорядковий хук (повний текст НЕ потрібен; це робота 06 лише для caption).

## Інфографіка — правила (фідбек Viktor)
- **Головний заголовок — ВЕРХНІМ РЕГІСТРОМ + по центру.**
- **Chart > text-grid:** воліємо діаграму, не текстову сітку. 4 рецепти: Donut/Pie · Funnel ·
  Growth Curve · Timeline (+ Comparison Table N×3, Step Grid 3×3 для структурних).
- Текст на кораловій підсвітці — завжди **БІЛИЙ**.
- **Фон лише БІЛИЙ** (ніколи cream/off-white) — Viktor накладає скріни/лого, що на білому.

## Single image — анатомія
- **Personal/TOFU** (Пт): власне фото автора (правило стратегії «власне фото»).
- **Expertise/stat:** брендований візуал — хук/цифра великим, кораловий акцент, автор-блок
  (фото+імʼя), вордмарк Victor Shulga. Скрін фреймворку/метрики, якщо є proof.

## Бренд (per-client)
- **Viktor:** білий фон + корал #E85A4F + charcoal, Inter Tight (заголовки) + Inter (текст),
  автор-блок + вордмарк. (Деталі — бренд-кіт Victor Shulga.)
- **Клієнти:** їхній бренд-кіт. Інваріант: ніколи не мішати корал персонального бренду у клієнтські креативи.

06 пише текст поста ПІД цей креатив (caption/хук для каруселі; повний пост для single image/infographic).
